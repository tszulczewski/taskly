# Lessons Learned

Long-term memory for AI agents working on this project. Read this file **before starting any task**.

## How to use

- Add a one-line entry to the index below for every lesson. Newest first.
- Put details (context, root cause, fix, how to avoid) in `.ai/lessons/YYYY-MM-DD-slug.md`.
- Small, self-explanatory lessons may live only in the index.
- Before adding, check for an existing lesson on the topic; update it instead of duplicating.
- Remove or correct lessons that turn out to be wrong.

- 2026-10-28 — When the brief supersedes a rule, the old rule also lives outside specs and issues: `.ai/docs/engineering-standards.md` §6 still said "subtask estimates are informational and never summed" (R06) after R12 replaced it, and `design-system.md` lists brief id ranges. Grep `.ai/docs/`, code TODOs and the design system for the superseded ids and their wording, not only the files the handoff names.

- 2026-10-27 — `om-synthetic-users` on a prototype: a decision simulation that describes a product rule ("subtask figures do not add up into the task") primes the persona if it comes before the walk, and the persona then "discovers" the rule on screen. Ask the past-tense questions, walk, and only then run the decision simulations; never hint at a control ("Details can be clicked") in a step message. Also: `agent-browser screenshot` with a relative path does not write into the repo — pass absolute paths.
- 2026-10-27 — An `sr-only` element (`position: absolute`) inside a row with `overflow-x: auto` escapes the row and widens the whole page unless the row itself is positioned: ThemeToggle's hidden labels in the prototype's review bar gave a 1015px page at 320px. Give scrolling rows `position: relative`, and find the culprit by listing elements whose right edge exceeds the page (`getBoundingClientRect().right + scrollX`), including absolute ones inside scrollers.
- 2026-10-26 — Tailwind generates only classes it finds as literal text: a class built with a template string (`` `[&_${sel}]:font-regular` ``) silently does nothing, and the story still passes `test:storybook`. Write arbitrary-variant classes out in full and check a computed style (`getComputedStyle`) in the browser. Also: the owner's running `storybook dev` (WSL) did not index a newly created `*.stories.tsx`; build `storybook-static` and serve it on another port instead of restarting their server.
- 2026-10-26 — A tone painted inside a rounded `Surface` (row hover, open row, edit form, dragged row) is square unless it follows the corners: the first and last task rows showed 90° corners on hover. The list must not use `overflow-hidden` (a row dragged past its edge, no `DragOverlay`, would be cut), so `TaskRow` rounds its own tones with `group/row` + `group-first/row:` / `group-last/row:` (and `group/subtask` for the last subtask). Headless Chromium reports `(hover: none)`, so `hover:` styles never show in agent-browser; check corners on the open row (same tone) or computed `border-radius`.
- 2026-10-26 — Shrinking `touch-target-min` (V1, 36px from 640px) breaks anything sized as "fits in the 44px block": the list skeleton's two meta bars (≈42px) made its row 57.7px against a 52px real row; `test:storybook` (TaskList › Loading) caught it, the numbers table given to the owner did not. When a size token changes, grep for components that rely on content fitting the old size and give the owner those numbers too. Also: `check:tokens` walks `.storybook/public`, so a built prototype there (minified bundle) gave 73 false hits; the script now skips that folder.
- 2026-10-26 — Review engine (`lekcja-07/silnik-przegladu`) with React: the engine focuses the arriving screen's heading synchronously, so remounting the arriving screen leaves focus on `body`; remount only the screen that was left. Keep one stable first child in `.frame`: the engine appends its pin layer there and comment anchors count same-tag siblings. Opening a Radix menu from script needs a `keydown` Enter on the trigger (`click()` does nothing); a menu item does react to `click()`. A modal dialog's scrim covers the review bar. `agent-browser open` with only a different `#hash` does not reload the page, so state from the previous walk stays: open `about:blank` first.
- 2026-10-23 — Before proposing a change to row geometry, measure it at 320px too: below 640px a task row always has two lines (the estimate sits under the title), so a fix described with desktop numbers ("rows with a meta line grow to 76px") changed every phone row (68 → 79px). U1 was approved on the desktop numbers and had to be asked again; give the owner the numbers for every width before they choose.
- 2026-10-23 — Stopping a server started with `npx http-server …` in the background: killing the `npm exec` PID leaves the `http-server` child running and holding the port, so the next start fails silently and the old process serves the files. Find and kill the process whose command is `http-server` (`ps -eo pid,args | grep '[h]ttp-server'`), in a separate call.
- 2026-10-23 — Focus after a dialog closes: the element you meant to focus may already be unmounted (the deleted row's "…", or the whole list after its last item, replaced by the empty state), and `.focus()` on a detached node silently leaves focus on `body`. Pick the first target that `isConnected`, with a focusable fallback (`tabIndex={-1}`) that is always rendered in that state; test the last-item case with a stateful wrapper that really removes the item (decision O4, `TaskList`).
- 2026-10-23 — Primitives such as `Surface` set `data-slot` after spreading props, so a `data-slot` passed to them is overwritten (only with `asChild` does the child's attribute win). Query a rendered `Surface` by `[data-slot="surface"]` or by role, not by the slot you passed. Same for `ErrorState`: its `data-slot="error-state"` is overwritten by `Alert` (`data-slot="alert"`), so query it by `role="alert"` (seen 2026-10-27).

- 2026-10-23 — `Tooltip` takes its text from its direct child's `aria-label`. Around a menu button (`<Tooltip><MenuTrigger asChild><Button …/></MenuTrigger></Tooltip>`) the child is `MenuTrigger`, so put the same `aria-label` on `MenuTrigger` as on the `Button`, or the bubble is empty (story Primitives/Tooltip › With Menu).

- 2026-10-22 — A component that is wider than a narrow docs preview (e.g. `AppHeader` in a 174px catalog column at 320px) widens the whole docs page; give that preview its own `overflow-x-auto` box with `tabIndex={0}` and a name (axe `scrollable-region-focusable`), using `role="group"`, not `role="region"`: a region is a landmark, and a `<header>` inside it fails `landmark-banner-is-top-level`. Check docs pages for `scrollWidth > clientWidth`, not just story canvases. Do this for all docs pages, not only the changed ones: on 2026-10-23, 11 of 72 pages scrolled at 320px because of `DoDont` examples, `SpacingRelations` and a narrow catalog cell. A flex/grid child also needs `min-w-0`, or its scroll box never shrinks.

- 2026-10-22 — Radix close autofocus runs on the next task (assert with `waitFor`); a menu item opening a form must prevent the menu's close autofocus; `autoFocus` stories on a docs page make it jump; regex names also match "More actions for …" → [details](lessons/2026-10-22-radix-focus-and-docs-autofocus.md)
- 2026-10-22 — Radix RadioGroup selects on arrow keys only if the key is still down when focus arrives, and roving focus moves in a `setTimeout`; `userEvent.keyboard("{ArrowRight}")` releases at once, so nothing gets selected. In play functions hold the key (`{ArrowRight>}`), `waitFor` the checked state, then release (`{/ArrowRight}`).
- 2026-10-22 — shadcn CLI in `packages/ui`: point `tailwind.css` in a temporary `components.json` at a scratch file (otherwise it writes its own colour variables into our CSS), and check `package.json` afterwards: with `"utils": "@/lib/cn"` it installs the unrelated npm package `cn` on every `add`. Rewrite generated imports to relative paths (`@/` collides with the app's alias).
- 2026-10-22 — Storybook frozen states: redefine `hover`, `focus-visible`, `active` (and custom variants such as `field-focus`) with `@custom-variant name (&:pseudo, &[data-preview-state~="…"])` in `.storybook/preview.css` only; the package CSS stays untouched. Without Tailwind's default theme `min-w-0`, `inset-y-0` compile to nothing; `theme.css` maps `--spacing-0: 0`.

- 2026-10-22 — Radix Tooltip always appends `aria-describedby` to its trigger (Slot `mergeProps` concatenates it, so passing `undefined` does not remove it). For an icon button whose tooltip repeats its `aria-label`, wrap the button in a role-less `<span>` as the `asChild` trigger and mark the bubble `aria-hidden`, so the name is read once.
- 2026-10-22 — `npx shadcn add` stops on an interactive "overwrite existing file?" prompt (e.g. `alert-dialog` wants to rewrite `button.tsx`) and hangs a non-interactive run until timeout. Add components one by one, back up `src/components/ui` first, or write the component directly on the Radix primitive.
- 2026-10-22 — Storybook stories of portalled overlays (menu, popover, dialog, tooltip): set `parameters.a11y.context: "body"` so axe checks the portal, query with `within(canvasElement.ownerDocument.body)`, and render them in docs with `docs.story.inline: false` plus a height, or the open overlays of several stories overlap on one docs page.
- 2026-10-22 — Storybook docs: `{word}` in MDX prose is a JS expression and breaks the whole page ("title is not defined"); put it in backticks — also inside quoted UI text like "Complete “{title}”" (it broke three pages again on 2026-10-22). Before building, `grep -n "{[a-z]*}" *.mdx` and check every hit is inside backticks or a code block. `test:storybook` runs stories, not MDX, so open every docs page of the built Storybook. Stories rendered in docs iframes (`docs.story.inline: false`) get no toolbar globals: mirror the docs page's root `data-theme` (frame id `iframe--<story id>`). Radix menus close when their window loses focus, so stories meant to show an open menu pin `open`.
- 2026-10-22 — Radix props that take numbers (`sideOffset`, `collisionPadding`) get token values at render time through `tokenPx` (`packages/ui/src/lib/token-px.ts`): `getComputedStyle(root).getPropertyValue("--token")` returns the value with `var()` resolved; convert rem with the root font size. `--radix-popper-available-width` already subtracts `collisionPadding`, so don't subtract the gutter again in CSS. The Storybook/Vite CSS minifier rewrites `rgb(… / 0.5)` tokens to 8-digit hex, so read a colour's alpha from a probe's computed `color`, not from the custom property text.
- 2026-10-22 — Moving focus to the first invalid field after an async submit: do it in `useLayoutEffect` (keyed on the errors), not `useEffect`; a passive effect can run after the message is painted, so tests (and screen readers) see focus still on the button. jsdom tests pass either way because `act` flushes effects; the Storybook browser test caught it.
- 2026-10-22 — dnd-kit: a play function that ends mid keyboard drag leaks window key listeners into the next story (Space disappears from inputs), so end with Escape; destructure `useSortable` (`react-hooks/refs`); `PopoverAnchor` needs an unconditional `Popover` root; jsdom needs a `ResizeObserver` stub for Radix inputs inside forms → [details](lessons/2026-10-22-dnd-kit-sortable-in-stories-and-tests.md)
- 2026-10-22 — Storybook story hooks (`useGlobals`, `useArgs`) work only when called directly in the story's `render` function (name it `function Render()` for the hooks lint rule), not in a nested component. `updateGlobals` does not change globals in the Vitest runner (no manager), so assert component state there and check the global change in the built Storybook. `userEvent.click` refuses an `aria-disabled` button with `pointer-events: none`; test a blocked second submit with Enter in a field.
- 2026-10-22 — After changing what `packages/app/app/globals.css` imports, `next build` can reuse a stale Turbopack CSS cache (old classes and variables, new ones missing) and still report success. Delete `packages/app/.next` and rebuild, then grep the CSS in `.next/static/chunks/*.css` for the new utilities.
- 2026-10-21 — Tailwind 4 token bridge: skip `tailwindcss/theme.css` and map tokens in `@theme inline reference { --*: initial; … }`. Plain `@theme inline` re-emits a variable with the same name as the token (`--radius-control: var(--radius-control)`, circular); `reference` emits nothing. Without the default theme, palette classes, `p-4`, `text-sm`, `rounded-lg`, `shadow-*` silently compile to nothing, so `npm run check:tokens` flags them.
- 2026-10-21 — Storybook 10: turn off the onboarding checklist with `features.sidebarOnboardingChecklist/menuOnboardingChecklist: false` and update notices with `core.disableWhatsNewNotifications`; test both themes with one Vitest project per theme via `storybookTest({ initialGlobals: { theme } })`. A11y gate is `parameters.a11y.test = 'error'` (verified: a low-contrast story fails in both themes).
- 2026-10-21 — `pkill -f <pattern>` inside a Bash tool call also matches the tool's own shell (its command line contains the pattern) and kills it (exit 144). The same happens with `kill $(pgrep -f <pattern>)` in one command (repeated 2026-10-23). Find the PID in one call (`ps -eo pid,args | grep '[h]ttp-server'`), kill it by number in the next.
- 2026-10-21 — Backlog stories have no per-story spec (issue bodies say so); check `.ai/specs/` before pointing decisions at "the spec for E0x-S0y". Decisions made before a spec exists go to `.ai/specs/research/decisions/` with a pointer in `backlog.md`.
- 2026-10-16 — The local dev DB role has no `CREATEDB`, and migrations hard-code the `"public"` schema, so tests that need a fresh database (e.g. applying `0000`, adding data, then applying later migrations) can't run locally. Run them only under Testcontainers (CI) and skip when `TEST_DATABASE_URL` is set.
