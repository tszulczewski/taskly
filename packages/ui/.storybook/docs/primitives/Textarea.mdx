# Textarea

`import { Textarea } from "@taskly/ui";`

## 1. What it is for

Lets the user write a few sentences about a task, such as which paint to buy or what to do first.

<Unstyled>
  <Story of={Stories.Playground} />
</Unstyled>

## 2. When to use

- The task description in quick-add "Details" and in the expanded row (spec E01, Luki 6). It is optional.

## 3. When not to use

| Situation                                      | Use instead                                                                | Source        |
| ---------------------------------------------- | -------------------------------------------------------------------------- | ------------- |
| A title, a name or an amount                   | `Input`                                                                    | spec E01      |
| Showing a description that is not being edited | plain text in the expanded row; `TextAction tone="muted"` when it is empty | Luki 6, R01.4 |

## 4. Anatomy

| Part          | Required | Notes                                                                       |
| ------------- | -------- | --------------------------------------------------------------------------- |
| Frame         | yes      | 1px `color-border-control`, `radius-control`, `color-surface-list` (T1, T8) |
| Text          | yes      | 16px below 640px, 15px above, `line-height-body` (Luki 1)                   |
| Placeholder   | optional | An example starting with "e.g." / "np."                                     |
| Resize handle | yes      | Vertical only, so the field never breaks the column width (WCAG 1.4.10)     |

| -------------------------- | ---------------------------------------------------------------------------- | ----------------------- |
| Empty                      | Placeholder example in muted text.                                           | R01.4                   |

## 7. Behaviour and accessibility

- **Keyboard:** Enter adds a new line (it does not submit); Tab leaves the field. Covered by the Playground test.
- **Name and description:** from FormField: visible label, hint and error through `aria-describedby` (WCAG 1.3.1, 3.3.2).
- **Target size:** at least three lines high, well above 44px.
- **Zoom on phones:** 16px text below 640px (Luki 1).

## 8. Content

- Label "Description" / "Opis", marked "(optional)" / "(opcjonalnie)" (spec E01, K5).
- No length counter in version 1: the spec sets no visible limit.
- Long text grows inside the field; the user can drag it taller.

## 11. Code

Minimal:

```tsx
<FormField label="Description" optional>
  {(field) => <Textarea {...field} />}
</FormField>
```

In Taskly: the description in quick-add details.

```tsx
<FormField label="Description" optional>
  {(field) => (
    <Textarea {...field} name="description" placeholder="e.g. Two coats, white matt paint" />
  )}
</FormField>
```
