# E04 Later (parked)

Backlog E04 (#14), priority low, risk low. The owner parked these items for version 2 (D13); nothing in this epic is scheduled or has a screen, and nothing in version 1 should look ready for them (R02.8, P03). The quick shopping list is the one item whose parts are ready, as recipes (below). This page exists so that every epic has one (decision L4); the full list also lives in [What is missing › Later](?path=/docs/design-system-what-is-missing--docs).

## Flow

None. The epic has no stories, no spec and no screens.

## Screens and stories

No screen and no component yet. The quick shopping list will be built from recipes that are ready: a list that is not tasks ([Patterns › List](?path=/docs/patterns-list--docs), decisions N1, N2, N5, N6, O5), adding by name alone ([Patterns › Quick capture](?path=/docs/patterns-quick-capture--docs), N3), changing an item that has only a name ([Patterns › Inline edit](?path=/docs/patterns-inline-edit--docs), O1) and deleting it ([Patterns › Delete confirmation](?path=/docs/patterns-delete-confirmation--docs), O2). Three design-system agent tests built the screen as an exercise, on branches that are not merged (`design/shopping-screen-agent-test`, `design/shopping-screen-agent-test-2`, `design/shopping-screen-agent-test-3`).

## Quick shopping list: what the agent tests left open

Three design-system agent tests (2026-10-23; the second after decisions N1–N11, the third after O1–O7) built this screen as an exercise, on branches that are not merged. The first log is `.ai/runs/2026-10-23-shopping-screen-agent-test.md`; the second and third logs live on their branches (`.ai/runs/2026-10-23-shopping-screen-agent-test-2.md`, `-3.md`). These questions belong to the product, not to the system; answer them in the E04 spec before the screen is built. Until then, where every test assumed the same, that assumption is the rule for the next screen or test; where they differ or one did not answer, the question stays open and is a guess (decision U4).
