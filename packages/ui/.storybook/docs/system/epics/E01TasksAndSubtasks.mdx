# E01 Tasks and subtasks

Backlog E01 (#11): E01-S01 add a task with a description and an estimate range (#15), E01-S02 subtasks with their own estimate, and the task's estimate becomes their sum (#16; brief refresh 2026-10-27, R12–R18, D22–D24). Spec: `.ai/specs/2026-10-16-tasks-and-subtasks.md` (PR A: data and services; PR B: routes and the screen; PR C: subtasks). Screens S5 and S6.

## Flow

1. The owner opens `/` and sees one list on one surface; while it loads, static grey rows.
2. They type a title in quick add, and the amount beside it if they know it, and press "Add" (or Enter). The row appears at once, muted with "Saving…", and is confirmed or rolled back with the message on the form; focus goes back to the title for the next task (C1).
3. The estimate is "Amount" and "up to (optional)": one amount is an exact price, both a range (R18, D24). Only the title is required; the description waits behind the "Description" toggle.
4. Pressing a task's title opens the row in place: the description, the subtasks and "Add subtask". The estimate stays at the right of the title from 640px and goes under it on phones.
5. "…" → "Edit" turns the row into the same form, filled in; Cancel or Save returns focus to "…".
6. "…" → "Add subtask" opens a form under the task. From the first subtask the task's estimate is the sum of its subtasks; the row counts "N subtasks without an estimate", a muted notice says the typed amount is kept, and the edit form shows the sum as text. When the last subtask goes, the typed amount comes back (R12, R13, R15; decision W1).
7. "…" → "Delete" asks once, naming the task and how many subtasks go with it; there is no undo.

## Components

`QuickAdd`, `TaskList`, `TaskRow`, `TaskForm`, `EstimateRange`, `DeleteTaskDialog` (`src/product/tasks/`); built on `Surface`, `Collapsible`, `Menu`, `FormField`, `Input`, `Textarea`, `TextAction`, `ConfirmDialog`, `Skeleton`, `EmptyState`, `ErrorState`.

## Decisions that shape it

- A list of rows, not cards or a board; one surface, rows divided by a line (R02.1, A01.2).
- The description shows only when the row is open; row actions are in "…" (Luki 6, R02.1, P2).
- The title is the row's one disclosure; the arrow from 640px is decorative (decision J1).
- An estimate is "1 200–1 500 zł", or "450 zł" for an exact price; "No estimate" when empty (R18, D24, tokens rule 5, F11).
- A task with subtasks shows their sum, unmarked (R12, decision W2); its typed figure is kept (R15).
- A change shows at once and rolls back with a message where it happened, never a toast (spec E01, P4).
