# Reorder

How the owner puts things in the order the work will happen, shown on the task list: drag by the handle, move with the keyboard, long-press on a phone, or step with Move up / Move down. Built from `DragHandle`, `TaskRow`, `TaskList` and `SortableGroup`.

## Rules

| Rule                                                                                                                               | Source                         |
| ---------------------------------------------------------------------------------------------------------------------------------- | ------------------------------ |
| A move sends only the moved row and its new neighbours (`afterId`, `beforeId`); the server gives it one new fractional `position`. | standards §5, §6               |
| Tasks move within the list; subtasks only within their own task. Nothing changes parent by dragging.                               | decision G1                    |
| From 640px a handle starts a drag; the rest of the row stays clickable.                                                            | decision G2, Luki 7            |
| Below 640px there is no handle: a long press on the row picks it up; a tap and scrolling work as usual.                            | decision G2, decision H1       |
| Every move can be done without dragging: keyboard on the handle, and Move up / Move down in "…".                                   | WCAG 2.1.1, 2.5.7, decision G2 |
| Rows move only up and down; the moved row lifts on the raised tone, the others make room over `motion-duration-quick`. No shadow.  | Luki 8, K2, tokens rule 1      |
| The move shows at once; if the server refuses, the row goes back and says so in the row.                                           | Optimistic change, decision H5 |
| Each step is announced by title: picked up, moved over, dropped, cancelled.                                                        | WCAG 4.1.3, decision H6        |
| Rows still being saved (pending) never move: their id is temporary.                                                                | spec E01                       |
| Completed tasks and subtasks do not move, and the server rejects such a move.                                                      | decision 2026-10-21 (E03)      |
| With reduced motion nothing animates.                                                                                              | Luki 8                         |

## Keyboard

| Key            | On the handle                     |
| -------------- | --------------------------------- |
| Space or Enter | Pick up the row; again to drop it |
| Up / Down      | Move the picked-up row one place  |
| Escape         | Put it back where it was          |
