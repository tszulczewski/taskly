# Place color picker

`import { PlaceColorPicker } from "@taskly/ui";`

## 1. What it is for

Lets the owner change a place's colour to one of the ten place colours, so places stay easy to tell apart in small dots (Luki 3). Any colour can be chosen, also one another place has: the app hands the colours out in turn and from the eleventh place they repeat, and the name always stands beside the dot (D26).

## 2. When to use

- Editing a place: changing its colour (decision G6, D26).

## 3. When not to use

| Situation                  | Use instead                              | Source |
| -------------------------- | ---------------------------------------- | ------ |
| Creating a place           | no choice: the app picks the next colour | D26    |
| Any colour outside the ten | not offered                              | Luki 3 |
| Choosing the theme         | `ThemeToggle`                            | Luki 2 |

## 4. Anatomy

| Part   | Required | Notes                                                                                                                            |
| ------ | -------- | -------------------------------------------------------------------------------------------------------------------------------- |
| Group  | yes      | A radio group named by `label` ("Colour"); the place form puts it in a `fieldset` with that legend                               |
| Swatch | yes      | A 44 × 44 px (36 × 36 px from 640px) target (`size-touch`) around a `size-icon` dot in `color-place-N`; named in words ("Olive") |
| Chosen | yes      | An outline in `color-text-primary` around the dot (`swatch-selected`, `focus-ring-width` / `focus-ring-offset`)                  |

## 5. Variants

None: it is used only when editing a place, with the place's colour chosen and every colour available (decision G6, D26). Until 2026-11-03 it also appeared from the seventh new place and blocked colours in use (G4, G5); D26 replaced both.

## 7. Behaviour and accessibility

- One Tab stop; arrow keys move to the next colour and choose it (radio group, WCAG 2.1.1).
- The chosen colour is shown by an outline, not by colour alone, and each swatch is named in words (WCAG 1.4.1).
- Every colour has at least 3:1 contrast on the surface in both themes (WCAG 1.4.11, `tokeny.md`).

## 8. Content

- Colour names are the token names: Blue, Ochre, Terracotta, Green, Violet, Pink, Olive, Plum, Teal, Slate (Luki 3, decision T4).
