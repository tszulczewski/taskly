# Task screens

Screens S5 (the task list at `/`) and S6 (a task opened in place) of spec E01, S7 (order, markers and places on the list; backlog E02-S01…S03, no spec yet) and S8 (completion and future expenses; backlog E03-S01, E03-S02, no spec yet), full screen inside the app shell. The server is simulated (P1): changes are confirmed after a short delay, refused, or never answered. Open a story to see it at its width.
