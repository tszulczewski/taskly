# Quick add

`import { QuickAdd } from "@taskly/ui";`

## 1. What it is for

Captures a task in one row, before it is forgotten: the title, the estimate beside it and "Add" (discovery prototype C1). Only the title is required; the amounts are there so the estimate goes in with the task, and the description waits behind its toggle. The form is ready for the next task straight away.

## 2. When to use

- Above the task list, as the one way to add a task (spec E01, Quick add; R02.9).
- Under an expanded task for its subtasks, with Cancel (spec E01, R02.9: a visible "Add subtask").

## 3. When not to use

| Situation                 | Use instead             | Source   |
| ------------------------- | ----------------------- | -------- |
| Changing an existing task | `TaskForm` in the row   | spec E01 |
| A form in a modal window  | not used for adding     | A03, Q2  |
| A subtask under a subtask | not offered (one level) | spec E01 |

## 4. Anatomy

| Part        | Required | Notes                                                                                                                       |
| ----------- | -------- | --------------------------------------------------------------------------------------------------------------------------- |
| Error       | optional | `Alert` above the form after a failed add; what was typed stays                                                             |
| Title       | yes      | Label "New task" or "New subtask"; Enter submits                                                                            |
| Estimate    | optional | A group "Estimate (optional)": "Amount" and "up to (optional)", `inputmode="decimal"`, suffix "zł" (R18, D24, spec E01, K5) |
| Add         | yes      | Primary `Button` at the end of the row; "Adding…" with a spinner while sending                                              |
| Description | optional | Muted `TextAction` "Description" with an arrow under the row; opens the field in place (W4)                                 |
| Cancel      | subtask  | Muted `TextAction` beside "Description"; Escape does the same                                                               |

## 7. Behaviour and accessibility

- **Keyboard:** title → Amount → up to → Add → Description (→ description; Cancel for a subtask). Enter in any one-line field submits. Covered by the Playground test.
- **After an add:** the field clears and focus stays in it (spec E01). The form counts as added only after the server confirmed, so a refused add keeps what was typed (decision F2).
- **Errors:** linked with `aria-describedby`; the form error is announced (`role="alert"`). A description with an error keeps Description open (decision F9).
- **Estimate:** a `fieldset` with the legend "Estimate (optional)", so a screen reader hears the group before "Amount" and "up to". One amount is an exact price; both, a range; neither, no estimate (R18, R10).
- **Description:** a disclosure button with `aria-expanded`; the arrow turns over `motion-duration-base` (Luki 8).
- **Targets:** fields, Add and Description are at least 44px high on phones, 36px from 640px (K1, V1).

## 8. Content

- Labels: "New task", "New subtask", "Estimate (optional)", "Amount", "up to (optional)", "Description" (spec E01, R18). Button: "Add".
- Messages: "Enter an amount like 1 500,50", "“Up to” must not be less than the amount." (spec E01). "Enter a title." and "Enter at most 10 000 000 zł" are examples; the real ones come from the shared schema (decision E3).
- Amounts accept Polish formatting: "1 500,50", "1500.5" (spec E01).

## 10. API

<ArgTypes of={Stories} />

`validate` applies the shared schema (`taskFields`, `parsePlnToGrosze`); `onSubmit` sends the typed text and the app converts amounts to grosze (P1).

## 11. Code

```tsx
<QuickAdd validate={validateTaskForm} onSubmit={(values) => createTask.mutateAsync(values)} />
```

In Taskly: under an expanded task, for a subtask.

```tsx
<QuickAdd
  validate={validateTaskForm}
  onSubmit={(values) => createTask.mutateAsync({ ...values, parentId: task.id })}
  onCancel={() => setAdding(false)}
  autoFocus
/>
```
