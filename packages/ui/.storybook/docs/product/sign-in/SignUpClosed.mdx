# Sign-up closed

`import { SignUpClosed } from "@taskly/ui";`

## 1. What it is for

Tells a visitor why they cannot create an account and gives them the way back.

<Unstyled>
  <Story of={Stories.Playground} />
</Unstyled>

## 2. When to use

- `/sign-up` while sign-up is closed, the default (Q1).

## 3. When not to use

| Situation        | Use instead  | Source |
| ---------------- | ------------ | ------ |
| Sign-up is open  | `SignUpForm` | Q1     |
| A failed request | `Alert`      | P3     |

## 4. Anatomy

| Part    | Required | Notes                                              |
| ------- | -------- | -------------------------------------------------- |
| Message | yes      | "Sign-up is closed. Ask the owner of this Taskly." |
| Link    | yes      | "Sign in" to `/sign-in`                            |

## 5. Variants

None.

## 6. States

Static: one state. It is information, not an error, so it is plain text, not an `Alert` (P3: alerts are for errors).

## 7. Behaviour and accessibility

The link is the only focusable element. No `role="alert"`: nothing failed.

## 8. Content

Exactly the spec's sentence; it does not say how to open sign-up (that is an operator step, Runbook).
