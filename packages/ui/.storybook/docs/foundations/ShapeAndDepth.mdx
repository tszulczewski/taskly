# Shape and depth

## Radius

Three radii and a circle. Nothing else is rounded; in particular not every element is a pill (A02).

## Borders

| Line                        | When                                                                                                                                     | Source           |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | ---------------- |
| `color-border-divider`, 1px | Between list rows, under the top bar. Decorative: it may be the only line between two rows because rows are told apart by their content. | R01.1, R02.1, T1 |
| `color-border-control`, 1px | Edges of fields and of an unchecked checkbox: they must reach 3:1.                                                                       | T1, WCAG 1.4.11  |
| No border                   | Around the list surface on the page: tone does the separating.                                                                           | R01.1            |

## Depth

Depth is tone, never shadow: page → list surface → raised row. There are no shadow utilities in the theme at all (tokens rule 1, R01.1). A dragged row is raised by `color-surface-raised`, not lifted with a shadow.
