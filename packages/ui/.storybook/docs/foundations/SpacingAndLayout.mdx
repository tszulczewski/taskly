# Spacing and layout

Spacing follows relations, not pixel values: pick the level that describes how two things relate, and use its token. The gaps grow from the inside out (T7).

## Layout

One content column, centred, at most `layout-content-max-width` (980px). No fixed sidebar (P01, R01.5). Version 1 has one screen, the task list with the future expenses line on it, so there is no navigation (decision E1). When a second screen arrives, navigation on phones sits at the bottom, with as many items as screens (P07, R02.11); that bar is not designed yet ([What is missing](?path=/docs/design-system-what-is-missing--docs)). The gutter is 16px up to 640px and 24px above (T7); `wide:` is the only breakpoint utility.
